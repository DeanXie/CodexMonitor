# P4.1e Compatibility / Migration Safety / Docs Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze P4.1a-d compatibility and failure semantics in one aggregate contract, refresh canonical documentation, and close P4.1 without changing product behavior.

**Architecture:** A deterministic JSON fixture is the machine-readable P4.1 closeout authority. A Node compatibility test validates that fixture against live version, release, platform-config, workflow, migration, activation, and startup artifacts; existing Rust/frontend suites continue to prove runtime behavior. Documentation links the aggregate contract to the existing slice evidence without claiming real user cutover or installed-package acceptance.

**Tech Stack:** Node test runner, JSON fixtures, existing Rust and Vitest suites, Markdown.

**Spec:** User-approved P4.1e request plus `docs/phase-4-0-truth-release-boundary.md` and the canonical P4.1a-d documents.

## Global Constraints

- No new product behavior unless a focused compatibility RED proves a small existing contract bug.
- No real user configuration, identity, daemon, endpoint, credential, installation, or profile cutover operation.
- Keep `0.7.68 · Build 5 · development`, including the required runtime-validation production bugfix.
- Keep real user cutover and installed-package acceptance `NOT_EXECUTED`; keep sudden power-loss durability `NOT_PROVEN`.
- Do not start P4.2.

## Review Focus

- A future platform override must not silently re-enable updater artifacts or drift desktop identity.
- A future typed settings field must not silently join the migration allowlist.
- `runtime_validated` must not be satisfied by file validation alone.
- Missing Remote token/pin must remain untrusted and must not auto-connect.
- App, daemon, and daemonctl explicit-root handling must stay fail-closed and aligned.
